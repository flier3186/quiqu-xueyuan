# 奇趣学园 · 孩子版使用手册（1 页）

> 这是你自己的数学乐园，跟着下面走就能玩起来！

## 怎么开始
1. 让爸爸妈妈打开「奇趣学园」的网址（或桌面图标）。
2. 选一个年级和想学的知识点，点「开始学习」。
3. 做完一题会自动进入下一题，直到今天的任务完成。

## 做题的时候会看到什么（按顺序）
| 步骤 | 是什么 | 你要做什么 |
| --- | --- | --- |
| STAGE 0 昨日回顾 | 复习昨天的内容 | 想一想，点「我想起来了」或「有点忘了」 |
| 微课卡 | 看一个小故事学方法 | 认真看，看完点继续 |
| 热身 | 数字感小游戏 | 抢答，答对 +1 金币 |
| STAGE 2 自己列一列 | 自己想想怎么算 | 在框里写你的想法，不用怕错 |
| STAGE 2.5 多解法对比 | 看看别人怎么算 | 对比一下，点错误的卡看看错在哪 |
| 正式解题 | 真正的题目 | 选答案，认真算 |
| 讲解 | 老师讲一遍 | 听懂了再继续 |
| 练习 | 同类题练一练 | 做对晋级，做错再学 |
| 完成 | 收获金币和星星 | 看看蛋蛋说什么 |

## 蛋蛋和奖励
- 每做对题、签到、热身抢答都会获得金币 💰。
- 做完口语对话获得 ⭐5 星。
- 金币可以陪伴蛋蛋成长，看看成就墙点亮了什么。

## 小工具
- 🧮 今日热身：点数快认 / 凑十 / 算式快抢，1100ms 一题，好玩。
- 🎤 蛋蛋追问：做完练习，蛋蛋会问「这道题你怎么算出来的？」说给蛋蛋听 +2 金币，打字告诉它 +1 金币，不想说可以跳过。
- 🔊 听题：不会读题目，点小喇叭。

## 小贴士
- 做错了没关系，看讲解再试一次，蛋蛋不扣金币。
- 每天 10-20 分钟刚刚好。
- 遇到不会的题，点「提示」按钮。
