# 奇趣学园 · 家长版使用手册

> 给自家孩子的私人数学教培系统（人教版 2024 主线，2-6 年级 + 7-9 扩展）。网页版 PWA，可离线使用，数据存在本机浏览器。

## 一、基本信息
- 线上地址：桌面浏览器打开即可（GitHub Pages 部署）。
- 离线安装：首次打开后浏览器可「添加到桌面」，断网也能用（Service Worker 缓存）。
- 更新：每次发布新版本会自动更新缓存；若页面异常旧，刷新一次。
- 数据存储：全部学习记录、设置、宠物进度都在**本机浏览器 localStorage** 里。⚠️ 换设备、清浏览器缓存之前，务必先备份（见 §五）。

## 二、家长入口
- 首页右下角「家长入口」按钮进入（若已设置密码，需输入 4 位家长密码）。
- 家长密码：可在入口内设置（4 位数字，不能用 1234），用于防止孩子改动设置与删除档案。

## 三、数学设置（家长面板 · 保存后下次开始做题时生效）
| 设置项 | 选项 | 说明 |
| --- | --- | --- |
| 📚 起点年级 | 二下 ~ 九下 | 孩子当前教材年级，决定默认出题范围 |
| 🎯 学习状态 | 刚学 / 学过但卡住 / 已经熟练 | 对应完整引导 / 跳 RME / 跳基础环节 |
| 📐 分数模型 | 全部模型 / 只展示圆形 | 初学阶段建议「只展示圆形」 |
| 🎬 动画速度 | 慢速 / 正常 / 快速 | 按孩子接受度调 |
| ⏱️ 单次学习时长 | 10 / 15 / 20 分钟 | 到点提示休息 |
| 🏃 前置引导 | 完整引导 / 直接做题 | 「直接做题」跳过微课卡/热身/引导发现，直接正式解题；**到期复习仍会优先出现**，做题后的讲解和练习保留。适合已熟练的题型 |

## 四、学习流程（家长了解即可）
7 阶段状态机：昨日复习（到期强制）→ 微课卡 → 热身 → RME 自己列一列 → Neriage 多解法对比 → 正式解题 → 讲解 → 练习 → 完成。孩子的每次对错都被 FSRS 间隔复习系统记录，「昨日回顾」自动安排到期内容。

## 五、💾 数据备份与恢复（最重要）
- 位置：家长面板「💾 数据备份」tab。
- **导出**：一键下载 `quiqu-backup-YYYYMMDD-HHMM.json`，含全部学习记录/设置/宠物/成就/API Key。请妥善保存（含密钥，勿外传）。
- **恢复**：选备份文件 → 确认后替换备份中已有的项目，**本机其他记录保留**（合并式，不会误删新数据）→ 自动刷新。
- 建议：每月导出一次；换设备前导出 → 新设备导入即可搬家。

## 六、AI 相关设置（如有配置）
- 家长面板 AI tab：可配置 Key（用于讲解/口语等 AI 能力）。Key 不回显明文（安全考虑）。

## 八、常见问题
- **Q：孩子说「做题前流程太多了」** → 家长面板「🏃 前置引导」切到「直接做题」。
- **Q：换电脑/清缓存后记录没了** → 清缓存前先导出备份；恢复时用「💾 数据备份」导入。
- **Q：怎么看孩子学得怎么样** → 首页总览有学习记录与掌握进度（真实数据）。
- **Q：忘记家长密码** → 家长密码存本机；确实忘记可清本机数据重设（会丢记录，先备份）。
